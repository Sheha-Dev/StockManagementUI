# AI Usage Documentation

## 1. AI Tools Used

I used ChatGPT as an AI assistant during the development of the Stock Management UI application.

The tools and their purposes are listed below.

| Tool | Purpose |
|---|---|
| ChatGPT | Getting guidance on Angular development, debugging errors, improving code structure, and understanding concepts. |
| ChatGPT | Generating suggestions for Angular Reactive Forms, form validation, and dynamic dropdown behavior. |
| ChatGPT | Troubleshooting API integration between the Angular frontend and ASP.NET Core Web API. |
| ChatGPT | Improving the user interface using SCSS and responsive styling. |
| ChatGPT | Preparing project documentation, including README.md and AI_USAGE.md. |

## 2. How AI Was Used

AI assistance was used for the following tasks:

- Understanding how to configure CORS to allow the Angular application to communicate with the backend API.
- Connecting the stock request form to the backend API through an Angular service.
- Improving the appearance and responsiveness of the stock request form.
- Preparing documentation for project setup, API integration, and version management.

AI-generated suggestions were reviewed and adapted to fit the existing project structure.
